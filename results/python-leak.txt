--- TIER 3b: the three talkie hits that look like code, checked ---
Each has a prose explanation. A story is not evidence, so each is
tested against the siblings it would have if the story were true.

  '==' as a section divider, not an operator — the ASCII-rule family:
    '=='=yes/0.062  '==='=yes/0.396  '===='=yes/0.235  '--'=yes/0.005  '---'=yes/0.031  '****'=yes/0.070  '____'=yes/0.044  '....'=yes/0.002
    Leader dots and rules are early merges throughout; '==' sits
    inside that family, where a Gutenberg text puts its separators.

  '->' as a typographic arrow, not a return annotation:
    '->'=0.083  '<-'=0.058  '=>'=0.220  '-->'=0.672  '<--'=0.812
    '<-' is as early as '->'. In Python '->' is syntax and '<-' is
    not, so a code corpus separates them; a corpus of chemistry
    arrows and cross-references does not. They are not separated.

  ' def' as a word-initial prefix fragment, not the keyword:
    peers: def=0.006  con=0.001  pre=0.002  dis=0.002  int=0.005  imp=0.004  ret=0.004
    earliest ' def…' merges: [' def', ' defe', ' defend', ' defendant', ' definite', ' defendants', ' defect', ' defence', ' defeated', ' defic', ' defeat', ' defense']
    Every continuation is prose. No ' def ' followed by an identifier,
    no '():'. The fragment exists because 1930 English says 'define',
    'defendant' and 'defence' constantly.

--- TIER 5: what if the language were not made of English? ---
Python is close to a BEST case for a 1930 English model: its
keywords are English words whose ordinary meanings match their
semantics (return, if, while, for..in, sum, len, sort, open, class).
Same task in every notation; only the surface language changes.

  SQL          total     69      18     17   1.06x      0.26
  COBOL        total    221      61     63   0.97x      0.28
  Python        high    127      36     32   1.12x      0.28
  Rust          some    146      52     47   1.11x      0.36
  Haskell     little     79      29     29   1.00x      0.37

  J             NONE     42      16     19   0.84x      0.38

  ratio vs o200k is nearly flat — it hides the effect, because o200k
  has no merges for J or APL either. tok/char is the discriminating
  measure, and it orders the languages by how much English they are
  made of. talkie BEATS o200k on COBOL and SQL: those are English.

  open / with / range / value — words a 1930 corpus knows, carrying

  leaked code, is the likeliest reason in-context Python works.
